# Código de conduta

## Compromisso

Este repositório é um artefato acadêmico aberto. Quem participa dele — mantenedores, revisores
ou qualquer pessoa que abra uma issue — se compromete a fazer da participação uma experiência
livre de assédio, independentemente de idade, corpo, deficiência, etnia, identidade ou expressão
de gênero, nível de experiência, nacionalidade, aparência, raça, religião ou orientação sexual.

## Comportamento esperado

- Linguagem acolhedora e objetiva.
- Crítica dirigida ao trabalho, nunca à pessoa. Aqui isso é literal: o projeto publica os
  próprios resultados negativos e uma tese falsificada. Apontar um erro técnico é contribuição,
  não ofensa — e receber esse apontamento também não é.
- Reconhecer autoria e proveniência de dados, código e ideias de terceiros.
- Aceitar com elegância a decisão dos mantenedores quando uma proposta não for incorporada.

## Comportamento inaceitável

- Linguagem ou imagens sexualizadas, assédio público ou privado.
- Ataques pessoais, insultos ou comentários depreciativos.
- Publicar informação privada de outra pessoa sem autorização explícita.
- Apresentar resultado, número ou citação como verificado sem tê-lo verificado. Neste projeto
  isso não é apenas descuido: a integridade do registro é o produto.

## Escopo

Aplica-se a todos os espaços do projeto — issues, pull requests, commits, discussões — e também
quando alguém representa o projeto publicamente.

## Aplicação

Relate condutas abusivas pelo formulário privado da aba **Security** do GitHub
(<https://github.com/out-of-sample/Quant-AI-Itau-2026/security/advisories/new>) ou, se ele não
estiver disponível, abrindo uma issue genérica pedindo contato dos mantenedores — sem expor o
conteúdo sensível.

Os mantenedores analisam todo relato, respondem de forma proporcional e preservam a
confidencialidade de quem relatou. Mantenedores que não cumprirem este código de boa-fé podem
ser afastados do projeto.
