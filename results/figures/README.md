# Figuras públicas

Estas figuras foram desenhadas para leitura no GitHub e não são recortes do relatório. Todas são
SVGs acessíveis, com título, descrição e fonte no próprio arquivo.

Regeneração:

```bash
python scripts/build_public_figures.py
```

As quatro figuras usadas no README têm versões PT/EN. Custos, sensibilidade, leave-one-out e
atribuição aparecem no [`atlas`](../README.md), em português. Cores têm função estável: verde para
resultado favorável/SERIEMA, azul para dados e benchmark, âmbar para decisão-base e terracota para
valor adverso.
