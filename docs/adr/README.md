# Architecture Decision Records

As decisões históricas do experimento estão no log cronológico
[`../07_RISCOS_E_DECISOES.md`](../07_RISCOS_E_DECISOES.md). Este diretório fica reservado a
decisões futuras de arquitetura de software que precisem de contexto, alternativas e
consequências próprias.

Use nomes sequenciais, por exemplo `0001-formato-de-cache.md`, a partir de
[`0000-template.md`](0000-template.md). Não crie ADR retroativo para reescrever uma decisão já
documentada; adicione um novo registro que a substitua explicitamente.
