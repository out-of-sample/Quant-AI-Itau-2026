# Histórico de pesquisa

Este diretório preserva **o que se acreditava e decidia em cada etapa**. Ele existe para impedir uma
história retrospectiva limpa demais: a tese original falhou, canais foram encerrados e a hipótese
final nasceu de uma reformulação explícita.

Para entender a SERIEMA hoje, comece pelo [`README`](../../README.md), pelo
[`método`](../methodology/README.md) ou pelos [`resultados`](../../results/README.md). Entre aqui
quando a pergunta for “como sabemos que isso não foi escolhido depois de ver o holdout?”.

## Política de preservação

“Histórico” não significa “descartável”. Pré-registros e decisões não são reescritos para coincidir
com a conclusão. Correções recebem nota datada; uma nova pesquisa cria nova especificação. O que
deixou de ser útil como navegação, porém, não precisa permanecer no nível principal da repo.
