# Arquivo de ideação

Este diretório preserva o trabalho anterior ao backtest que definiu o espaço de busca da
pesquisa:

- [`teses_candidatas.md`](teses_candidatas.md): 21 teses avaliadas e as razões, registradas
  antes de observar retornos, para escolher a tese climática;
- [`pipeline_e_portfolio.md`](pipeline_e_portfolio.md): esqueleto inicial do pipeline e da
  tradução de sinal em carteira.

Os arquivos são históricos. A especificação executada, suas reformulações e o resultado selado
estão em [`01_TESE_E_PRE_REGISTRO.md`](../../01_TESE_E_PRE_REGISTRO.md),
[`04_PROTOCOLO_BACKTEST.md`](../../04_PROTOCOLO_BACKTEST.md) e
[`holdout_result_v1.json`](../../../data/reference/holdout_result_v1.json).

Preservar as alternativas descartadas reduz o viés de sobrevivência narrativo: a repo não
apresenta a tese escolhida como se tivesse sido a única ideia considerada.
